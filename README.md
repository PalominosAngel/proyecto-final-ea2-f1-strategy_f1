# Proyecto Final EA2 - Programación para la Ciencia de Datos

## Tema
Predicción y análisis de estrategias de parada en pits en Fórmula 1 usando el dataset `f1_strategy_dataset_v4`.

## Objetivo
Aplicar un flujo completo de ciencia de datos: exploración, preparación, modelado supervisado, modelado no supervisado, optimización de hiperparámetros, evaluación, visualización y documentación final.

## Estructura del proyecto

```text

├── Dataset/

│   │   └── f1_strategy_dataset_v4_ENTRADA.csv
│   └── Despues/
```

## Cómo ejecutar

1. Abrir la carpeta completa en Visual Studio Code.
2. Instalar dependencias:

```bash
pip install -r requirements.txt
```

3. Abrir y ejecutar el notebook:

```text
Notebook/notebook_f1_strategy_final.ipynb
```

## Entrega sugerida
Subir a AVA el `.zip` completo junto con el notebook y la presentación si la plataforma los solicita por separado.
